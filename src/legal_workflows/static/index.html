Legal AI Workflows

Four AI agent workflows I built for a personal injury law firm, rebuilt on synthetic data. Run each one below, or connect an AI agent to the MCP server at the bottom of the page.

All names, cases, amounts and addresses here are fictional. No real client or firm data is used.

Medical Provider Audit .xlsx

Pulls every medical provider on a case into a review-ready spreadsheet with dropdowns, frozen headers and a provider-count check.

E-filing Document Renamer table

Turns court-document captions into standard filenames, with a confidence rating. Rows that need a person's review sort to the top.

Provider Reductions PDF letters

Drafts reduction letters from ledger data: a percentage off the bill for medical providers, and an interest-only reduction for litigation-funding companies.

Case Treatment Auditor report

Checks whether the client is still treating, reconciles the ledger against bills and records, and lists red flags tied to their source.
